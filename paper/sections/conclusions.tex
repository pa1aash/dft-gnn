\section{Conclusions}
\label{sec:conclusions}

For the deep, localised neutral oxygen vacancy in ordered non-magnetic oxides, the pristine crystal structure with the vacancy site marked reproduces, to within the tolerance, the accuracy of the descriptor network, once a graph network has learned from several hundred computed oxides. From \numNetNStar{} training oxides the structure-only network matches the same network given the \numRfElectronicNFeatures{} pristine-cell electronic descriptors to within \numNetTolerance{}~eV: the descriptors still lower the site error, by $A = \numNetHeadlineA{}$ [\numNetHeadlineALo{}, \numNetHeadlineAHi{}]~eV with $U = \numNetHeadlineAUpper{}$~eV, their benefit lies between oxides, not within them, and predicting them from structure first never beats structure alone. Given one class at a time rather than together, the descriptors still improve on structure alone by about the tolerance (Section~\ref{sec:disc_principal}), so the match bounds what the full descriptor set adds to this network, not what pristine-cell electronic information can add.

For screening, the number of computed oxides at hand fixes the model. With \numCfgBudgetsHostsItemThree{} training oxides or fewer, a random forest on the pristine-host descriptors is as accurate as either network or better; between \numCfgBudgetsHostsItemThree{} and \numCfgBudgetsHostsItemFour{} the descriptor network overtakes it and remains the most accurate model up to \numCfgBudgetsHostsItemFive{}; from \numNetNStar{} training oxides on, the structure-only network matches it, needs no DFT calculation of a new host and is insensitive, at the error measured, to host structures relaxed with a machine-learned interatomic potential.
