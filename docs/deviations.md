# Deviations from the pre-registered analysis plan

Every departure from `docs/ANALYSIS_PLAN.md` (tag `prereg-v1`) is logged here, before the affected run,
with the date, the plan section, the deviation, the reason and the impact. All deviations are reported in
the SI. Results generated before a deviation are retained and reported.

| date | section | deviation | reason | impact |
|---|---|---|---|---|
| 2026-10-06 | §11 | CLARIFICATION (does not alter any pre-registered decision). LOCO grouping is S02 definition ii-a: the set of distinct periodic-table groups of the host's cations (lanthanides and actinides in group 3). This gives 133 families over the 824 hosts of the K21 ML subset (S02, `docs/data_audit.md` §5) and 131 over the 818 hosts of universe v1. `config: robustness.loco.grouping = s02_definition_ii_a_distinct_group_set` | The plan names definition ii without choosing between its two variants (ii-a, set of distinct groups; ii-b, multiset over cations). ii-a is the stricter, coarser grouping: fewer and larger families, so each held-out family is more chemically distinct from the training families. | None on any pre-registered value. Fixes the family count for the k = 5 GroupKFold. |
| 2026-10-06 | §5 | CLARIFICATION (does not alter any pre-registered decision). Early stopping counts an epoch as an improvement whenever the validation MAE is strictly lower than the best so far. `config: training.early_stopping.min_delta = 0.0` | The plan fixes the monitored quantity and the restore-best rule but leaves min_delta unstated. A zero threshold is the neutral choice and adds no tuned value. | None on any pre-registered value. |
| 2026-10-06 | §5 | CLARIFICATION (does not alter any pre-registered decision). The validation-split seed of resample r, budget B and training seed s is `int.from_bytes(sha256(f"val\|{r}\|{B}\|{seed}".encode()).digest()[:4], "big")`, passed to `dftgnn.split.val_split`. On the Kiyohara split the released validation hosts are used and no seed is drawn. `config: training.validation.seed_rule = sha256_val_r_B_seed_first4_bigendian` | The plan states that the seed derives from (r, B, seed) but not how. A hash is platform independent and independent of Python's salted hash. | None on any pre-registered value. |
| 2026-10-06 | §5 | CLARIFICATION (does not alter any pre-registered decision). Rule for the two values the plan leaves to S07 (`training.max_epochs`, `training.early_stopping.patience`), logged before any run that informs it. Pilot: model S, fixed mid-space hyperparameters (lr 1e-3, weight decay 1e-5, hidden width 64, 3 MEGNet blocks, dropout 0.1, batch size 32, readout width 64, set2set), budgets 25, 200 and 654 of resample 0, seed 0, max_epochs 1500, early stopping disabled, validation MAE logged every epoch; the test hosts are never loaded or evaluated. Rule, verbatim: "e_conv(B) = the first epoch at which the validation MAE is within 1% of that run's minimum validation MAE. max_epochs = the smallest multiple of 50 that is >= 1.5 x max over B of e_conv(B). patience = max(30, round(0.15 x max_epochs))." Conventions: epochs are counted from 1; "within 1%" means validation MAE <= 1.01 x the run's minimum; round is round-half-up. The resulting values are written to the config and logged in a further row with the evidence. | The plan fixes neither value and defers both to S07 "from the benchmark" (§5). A rule written down before the pilot runs removes any choice after seeing the curves, and the 1.5x margin and the 15% patience scale with the slowest-converging budget. | None on any pre-registered value. Sets two values that the plan leaves open. |
| 2026-10-07 | §5 | CLARIFICATION (does not alter any pre-registered decision). `training.max_epochs` = 200 and `training.early_stopping.patience` = 30, set by the rule logged on 2026-10-06. `config: training.max_epochs = 200` `config: training.early_stopping.patience = 30` Evidence (model S, mid-space hyperparameters, resample 0, seed 0, 1500 epochs, early stopping disabled, test hosts never evaluated; `results/pilot_epochs/`, `results/pilot_epochs.json`, curves in `results/pilot_epochs/curves.csv`): budget 25 (22 train / 3 val hosts): minimum validation MAE 1.163 eV at epoch 30, e_conv = 30; budget 200 (180 / 20): minimum 0.654 eV at epoch 71, e_conv = 70; budget 654 (589 / 65): minimum 0.327 eV at epoch 133, e_conv = 133. max over B of e_conv = 133; 1.5 x 133 = 199.5, so max_epochs = 200; 0.15 x 200 = 30, so patience = max(30, 30) = 30. | Applies the rule logged before the pilot; no value was chosen after seeing the curves. | None on any pre-registered value. The rule was calibrated at untuned mid-space hyperparameters; tuned configurations with a much smaller learning rate may converge more slowly than 200 epochs and would be truncated by the cap (reported in the S07 handoff). |
