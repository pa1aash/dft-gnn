**Figure S1.** Filter cascade that defines universe v1. Starting from the completed neutral oxygen-vacancy entries of the Kumagai et al. release, the cascade keeps the neutral machine-learning subset of that work (which already excludes perturbed-host-state entries, entries with undetermined band edges and dynamically unstable hosts), then applies three filters in order: D1 removes entries flagged as vacancy split, unknown defect type or not in the same configuration as the initial one; D2 removes the host Sr2Zr7O16, whose machine-learning site labels do not match the release targets; D3 keeps an entry of the two hosts with inconsistent cell metadata only if its vacancy site maps to an oxygen atom with a matching first cation shell (it removes nothing). Dashed boxes are the excluded entries of each step. Site and host counts after every step are in Table 1 (`results/filter_cascade.json`).
